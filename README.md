# Vajra

Landing page for **Vajra**, a National Weather Big Data Analytics platform for Smart India Hackathon 2026 (SIH26069 — Ministry of Earth Sciences / IMD).

## Develop

```bash
npm install
npm run dev
```

## Build and preview

```bash
npm run build
npm run preview
```

Production files are written to `dist/`. Open `dist/index.html` or serve that folder.
